ReviewArc opens to a unified inbox of real GitHub pull requests. It creates isolated, application-managed Git caches only when you open a pull request, then uses Codex in read-only mode to organize the change into a guided review.

<CardGrid>
  <Card title="One review inbox" icon="list-format">
    Bring review-requested, assigned, and authored pull requests from selected repositories into one place.
  </Card>
  <Card title="Evidence, not verdicts" icon="magnifier">
    Separate facts, inferences, risks, unknowns, and tests—and trace claims back to the reviewed revision.
  </Card>
  <Card title="Local by design" icon="padlock">
    Keep managed repositories, analysis, progress, drafts, and private notes on your Mac.
  </Card>
</CardGrid>

ReviewArc helps you move through a review deliberately. It does not approve code for you, and it never publishes to GitHub without an explicit confirmation.
